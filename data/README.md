# Data

## Source

This project uses the IBM Telco Customer Churn dataset:

- [IBM dataset repository](https://github.com/IBM/telco-customer-churn-on-icp4d)
- [Kaggle dataset page](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)

## Local setup

1. Download the CSV from one of the sources above.
2. Create a local folder named `data/raw/`.
3. Save the CSV as `data/raw/WA_Fn-UseC_-Telco-Customer-Churn.csv`.
4. If your downloaded filename differs, update the path used in the notebook.

## Data policy

Raw data is not committed to this repository. This keeps the repository lightweight and avoids redistributing data without checking the source's applicable terms. Do not upload private, personal, or licensed data.
