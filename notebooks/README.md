# Notebooks

Use numbered notebooks so the analysis can be followed in order.

Planned sequence:

1. `01_data_exploration.ipynb` — load the dataset, inspect dimensions and schema, check missing values and duplicates, and explore the target distribution.
2. `02_feature_analysis.ipynb` — analyze churn patterns and relationships between features and the target.
3. `03_modeling_evaluation.ipynb` — build a baseline model and compare candidate classifiers.

Keep notebooks focused, explain decisions in Markdown, and avoid committing large generated outputs.
